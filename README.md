# AUTO Scroll

A native Android auto-scroller built with Kotlin and XML layouts.

## Open in Android Studio

1. Clone this repository or download it as a ZIP.
2. Open the repository root in Android Studio.
3. Allow Gradle sync and install the Android SDK platform requested by the build.
4. Run the `app` configuration on a device or emulator.

## Current starter setup

- Kotlin + Android Views/XML
- Gradle Kotlin DSL
- Accessibility service declaration for timed swipe gestures
- Overlay permission support for a floating control bubble
- Minimum Android version: Android 7.0 (API 24)

The initial screen is a scaffold. Accessibility permission must be enabled manually in Android Settings before automatic swiping can work.
